# 《失序者的生存守则》最终策划方案
> 综合原策划案 + 当前代码实现 + 作者反馈，取最优方案

---

## 一、核心设计原则

- **剧情驱动，非时间驱动**：关键剧情由道具拾取/区域触发，不依赖实时时钟
- **压力适度**：恐怖感来自氛围和演出，不靠数值惩罚折磨玩家
- **规则即玩法**：每层一条简单规则，违规=死亡，没有模糊地带

---

## 二、理智系统（Sanity）

| 项目 | 方案 |
|------|------|
| 上限 | 100 |
| 扣理智 | 惊吓事件、目睹死亡、特定剧情（由脚本 `reduce_sanity()` 调用） |
| ~~黑暗持续掉理智~~ | **取消** — 道具稀缺时压力过大 |
| 恐慌模式 <50% | 保留：体力消耗×1.5、画面暗角脉动 |
| ~~文字认知污染~~ | **可选**：如果后续想加，在 UI 层做字符替换即可，不影响核心 |
| 归零 | 精神崩溃→Game Over |
| 恢复道具 | 镇定剂（+25理智），全游戏稀有分布 |

---

## 三、体力系统（Stamina）

| 项目 | 数值 |
|------|------|
| 走路消耗 | 0.5/秒（保持当前） |
| 跑步消耗 | 5.0/秒（保持当前） |
| 站立恢复 | 2.0/秒（保持当前） |
| 脱力阈值 | 归零→锁定移动→恢复至30%解除 |
| ~~安全房间双倍恢复~~ | **取消** — 游戏节奏紧凑，不需要 |

---

## 四、时间系统

| 项目 | 方案 |
|------|------|
| 时间流逝 | **事件驱动**（`set_time()` 手动推进），不自动流逝 |
| ~~时钟HUD~~ | **取消** — 时间由剧情控制，玩家不需要看时钟 |
| 禁忌时段 | 23:00-07:00 判定保留，由脚本在特定事件触发 |

---

## 五、照明系统

| 项目 | 方案 |
|------|------|
| 手机光 | 默认照明。亮度=手电筒，范围小（scale 1.5）。始终可用 |
| 手电筒 | **稀有道具**，全游戏只有1-2把。范围大（scale 2.8），锥形光束 |
| 电池 | **新增**。手电筒有电量条，使用中持续消耗。电池散落在各楼层作为可拾取资源 |
| 火柴 | 保留当前机制（圆形光，10秒消耗品）|

### 电池系统设计
- 手电筒满电量：100
- 消耗速率：2/秒（满电可用50秒）
- 电池道具：+50电量
- 电量归零：手电筒自动切回手机光
- 电量条：手电筒激活时在HUD上显示

## 六、物品系统（精简版）

### 保留的物品
| 物品 | 类型 | 说明 |
|------|------|------|
| 手机 | 关键 | 序章拾取，手机光照明 + 查看聊天记录 |
| 手电筒 | 稀有 | 1-2把，强力照明但消耗电池 |
| 电池 | 消耗 | 散落各层，补充手电筒电量 |
| 火柴 | 消耗 | 圆形照明10秒 |
| 镇定剂 | 消耗 | 恢复理智+25 |
| 能量饮料 | 消耗 | 恢复体力+40，极稀有 |
| 规则纸条 | 关键 | 每层获取，规则载体 |
| 耳塞 | 关键 | 第二层过关道具 |
| 绳子 | 关键 | 第三层过关道具 |
| 电梯卡 | 关键 | 每层通关道具 |

### 需要清理的物品
| 物品 | 原因 |
|------|------|
| 面包、罐头 | 无HP/饥饿系统 |
| 绷带、解毒药 | 无伤口/中毒系统 |
| 护身符、软底鞋 | 过度设计 |
| 可疑糖果 | 改为正面道具"甜食"（+15理智），或直接删除 |

### 需要清理的系统
| 系统 | 原因 |
|------|------|
| 异常状态（poison/bleed/cold/frightened/weak） | 策划无此设计，游戏不需要 |
| Buff系统（speed_up/down/silent_step/sharp_eye/tough） | 过度设计 |

### 考虑后续添加的物品
| 物品 | 说明 | 优先级 |
|------|------|--------|
| 消防斧 | 破门/窗，消耗15体力 | 中（看关卡是否需要多路径） |
| 录音笔 | 播放妹妹声音，声控机关/引开怪物 | 低（需要配合关卡设计） |

## 七、关卡流程（最终版）

### 序章-房间
1. 黑屏渐亮 → 姐姐独白（带头像对话框）
2. **手机聊天记录**（和妹妹的对话，交代背景）← 待实现
3. 拾取手机 → 背包教程
4. 出门到街道

### 序章-街道
1. 镜头演出展示街景 + 城市BGM
2. 自由探索街道
3. **可拾取：手电筒**（替换当前的耳塞、绳子）
4. 进入公寓 → 声音瞬断 → 黑暗

> ⚠️ 耳塞和绳子需要移回第二层和第三层各自的位置

### 第一层 —「禁止对视」
1. 众人入场对话
2. 分组探索，寻找电梯卡
3. 23:00事件触发 → 林佳语警告 → 灯光异变
4. 沈薇灵魂互换发生（**立绘上体现左右手差异**，不需要代码检测）
5. 07:00 → 灵魂回归 → 发现电梯只能向上
6. BGM：3首轮播

### 第二层 —「禁止离群」
1. 高跟鞋音效贯穿
2. 余凡留守电梯口 → 离群 → 被杀（剧情演出）
3. 沈薇负气出走 → 离群 → 被杀
4. 鹿可落单 → 玩家用耳塞 / 木头人静止救援
5. 找到电梯卡 → 上楼

### 第三层 —「禁止跑步」
1. 人形怪物缓步追逐（禁止跑步）
2. 周锐恐慌跑步 → 深渊巨口吞噬
3. 绳子绑住肉身 → 主动对视换魂 → 操控怪物跑步 → 巨口吃掉怪物
4. 07:00灵魂弹回
5. **追逐战小游戏**（当前代码有，保留）

### 结局
1. 电梯关门 → 规则纸浮现"她在说谎"
2. Demo结束 + 致谢

## 九、灵魂互换设计说明

| 要素 | 方案 |
|------|------|
| 触发方式 | 剧情脚本触发（不需要实时"对视检测"） |
| 沈薇伏笔 | 通过**立绘差异**（左手持物→右手持物）让玩家察觉 |
| 第三层换魂 | 玩家主动选择 → 操控怪物身体 → 追逐战 |
| 限制 | 每晚一次（由剧情自然保证，无需硬编码限制） |
