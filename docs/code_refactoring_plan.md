## 重构建议

### 1. 优先级：高（影响游戏运行）

#### 类型推断问题
**问题**：GDScript 4.6 对 `:=` 类型推断更严格
**影响**：可能导致解析错误和崩溃
**解决方案**：
- 使用显式类型注解 `var x: Type = ...` 代替 `var x := ...`
- 特别是 `.get()`、数组索引等返回 Variant 的情况

**示例**：
```gdscript
# ❌ 错误
var data := some_dict.get("key", {})
var msg := messages[index]

# ✅ 正确
var data: Dictionary = some_dict.get("key", {})
var msg: Dictionary = messages[index]
```

#### 缺少函数注释
**问题**：28% 的函数没有注释
**影响**：代码可读性和维护性差
**解决方案**：为所有公共函数添加 `##` 注释

### 2. 优先级：中（代码质量）
