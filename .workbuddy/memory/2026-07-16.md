### BUG 修复：F3 控制台跳到第一层无效
用户反馈：按 F3 点"第一层"，只左上角出现"已存档"提示，玩家位置没变、场景没切换。
**根因（既有 bug，与阶段一迁移无关）：** `scenes/levels/floor_1.tscn` 的根节点 `Floor1` **缺少 `script = ExtResource(...)` 绑定**，整个文件没有任何指向 `floor_1_scene.gd` 的 ext_resource。对比 `floor_2.tscn` 根节点 `Floor2` 明确有 `script = ExtResource("1")`。
现象解释：`change_floor(FLOOR_1)` 照常发出 `floor_changed` → SaveManager 自动存档 → "已存档"提示出现；但 `change_scene_to_file(floor_1)` 加载的是一个**没挂脚本的普通 Node2D**，`floor_1_scene.gd._ready()` 不运行 → 无玩家/无逻辑，表现为"没跳过去"。其余关卡场景（floor_2/3、prologue、ending、电梯）根节点均正常绑脚本，唯独 floor_1 缺。
**修复：**
- `floor_1.tscn`：`load_steps=10`→`11`；新增 `[ext_resource type="Script" path="res://scripts/levels/floor_1_scene.gd" id="11_flr"]`；根节点加 `script = ExtResource("11_flr")`。
- 顺手纠正阶段一迁移**无意引入**的两处（均非 F3 bug 根因，但应忠实于迁移前）：
  - `level_base_v2.gd` 里背包 UI 被脚本从 `Control.new()+set_script(inventory_ui.gd)` 误改成 `load(inventory_ui.tscn).instantiate()` → 已改回原写法。
  - 迁移脚本把 `level_base_v2.gd` 写成了 CRLF 行尾 → 归一为项目统一的 LF。
- 归一化后用 `git HEAD` 原始 v1 对比：除 `class_name LevelBase→LevelBaseV2` 外内容完全一致，确认迁移忠实。
